# Adv.Metrics Assignment 2026

Graduate econometrics assignment on fixed-\(G\) cluster inference using the Bester, Conley, and Hansen cluster covariance estimator.

Main files:

- `Report.pdf`: rendered assignment report.
- `Report.Rmd`: R Markdown source for the report.
- `run_sim.R`: Monte Carlo driver.
- `helpers.R`: DGP, grouping, and variance-estimator functions.
- `make_figures.R`: figure-generation script.
- `output/figures/`: generated figures and draw.io decision diagram.
- `references.bib`: bibliography.
