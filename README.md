# Adv.Metrics Assignment 2026

Graduate econometrics assignment on fixed-\(G\) cluster inference using the Bester, Conley, and Hansen cluster covariance estimator.

For a fully reproducible version of the project, work from `code_and_data/`. That folder contains the report source, the derived data, the scripts, and the generated outputs needed to rerun the analysis from the report project root.

Main files:

- `Report.pdf`: rendered assignment report.
- `Report.Rmd`: R Markdown source for the report.
- `code_and_data/README.md`: reproduction guide for the full bundle.
- `code_and_data/Report_HiClimR_BCH.Rmd`: report source used for the reproducible bundle.
- `code_and_data/analysis_data/weather_conflict_panel.rdata`: derived panel used in the empirical application.
- `code_and_data/output/`: generated figures, tables, and clustering outputs.
- `references.bib`: bibliography.
